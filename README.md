## What it does

A small deterministic Python program that writes one sentence to
`/output/entry.txt` (235 characters, UTF-8). The sentence is a pitch
meant to convince a friend who has never coded to let an AI agent build
their first app idea on make.fun — describe the idea in plain words,
get a working first version for free, no code, nothing to install, and
finally see it on a screen instead of only in your head.

## How to run it

```sh
python3 main.py
```

It creates `/output` if needed and writes the sentence to
`/output/entry.txt`. It needs no network, no keys, and no dependencies
beyond the Python standard library. Running it twice produces
byte-identical output.

## The sentence

> Describe the app idea you've been carrying in your head to an AI
> agent on make.fun, and it'll build you a working first version for
> free — no code, nothing to install, and you'll finally see it on a
> screen instead of only in your head.
